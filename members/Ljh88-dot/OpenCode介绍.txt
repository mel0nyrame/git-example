========================================
OpenCode 介绍 —— 开源 AI 编程代理
========================================

【它是什么】

OpenCode 是一个完全开源的 AI 编程代理（AI Coding Agent），
由 SST 团队开发，以 MIT 许可证发布在 GitHub 上。
它帮助你用任意 AI 模型来编写和运行代码，
既可以在终端里使用，也提供桌面应用、IDE 扩展和网页端。

官方数据显示：超过 220,000 个 GitHub Star、950 位贡献者、
20,000+ 次提交，月活跃开发者超过 1600 万，
是目前增长最快的开源 AI 编程工具之一。

----------------------------------------
【核心亮点】

1. 模型自由
   - 内置一组免费模型，无需注册账户即可使用；
   - 通过 Models.dev 支持 75+ 家 LLM 提供商（Claude、GPT、Gemini 等）；
   - 支持连接本地模型；
   - 可复用你的 ChatGPT Plus/Pro 或 GitHub Copilot 订阅。

2. 多会话并行
   在同一个项目里同时启动多个代理，各自并行处理不同任务。

3. LSP 加持
   自动为模型加载正确的 LSP（语言服务器），
   让 AI 具备真实的代码导航和理解能力。

4. 隐私优先
   不存储你的任何代码或上下文数据（使用其免费模型时除外），
   适合对隐私敏感的环境。

5. 会话分享
   任何会话都可以生成链接，方便调试和协作。

6. 零成本起步
   自带一组免费模型，开箱即用。

----------------------------------------
【四种使用形态】

- 终端 TUI：原生终端界面，响应式、可换主题，经典形态；
- 桌面应用：独立桌面端应用；
- IDE 扩展：嵌入常用编辑器的插件形态；
- 网页端：浏览器内直接使用，无需安装。

----------------------------------------
【安装方式】

# 官方脚本安装（macOS / Linux）
curl -fsSL https://opencode.ai/v2/install | bash

# 或通过 npm 全局安装
npm install -g opencode-ai

# 终端里启动，输入 opencode 即可进入会话
opencode

OpenCode = 开源 AI 编程代理 + 终端/桌面/IDE/网页四端形态
