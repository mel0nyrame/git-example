# 成员文件

每个人在这里创建属于自己的文件夹。

## 规则

1. 新建以你的 GitHub 用户名为名称的文件夹。
2. 只在自己的文件夹内改动 `用户名.txt`、`用户名.md` 和任意名称的 `.html` 文件。可以只改其中一种文件，也可以添加多个网页。
3. 内容自定，建议写自我介绍；不要写真实姓名。
4. 文件必须直接放在自己的文件夹下，不能放入子目录。不要提交图片、符号链接、子模块、`.DS_Store` 或其他附加文件。
5. 新增、修改、删除和重命名都不能超出上述范围。维护者 `mel0nyrame` 不受文件范围限制。

以用户名 `octocat` 为例：

```
members/
└── octocat/
    ├── octocat.txt
    ├── octocat.md
    └── index.html
```

提交流程和 commit、PR 规范见 [根目录 README](../README.md)。
