给学习中的自己提个醒

How I Work
01

先跑通，再优化

先让它跑起来，再想怎么变好看、变好用。饭一口口吃，bug 一个个改。

02

提问时，把前情提要带上

哪里卡住了、试过什么，尽量说清楚。不让队友兼职当读心师。

03

小步提交

一次改一点，提交说明写清楚。给未来的自己留条线索，别只留一句「改了」。

04

及时记录与回顾

踩过的坑记一下。下次再遇到，希望能说「这题我见过」，而不是「怎么又是你」。

05

先给自己立三个小目标

Goals
Git 完成一次真实的 Pull Request 体验一下和别人一起把代码改好的过程。
Build 用 Agent 从 0 做一个小工具 从「我有个想法」走到「你点开试试」。
Basics 继续打牢编程基础 多写、多理解，争取讲代码时不用全靠「感觉」。
