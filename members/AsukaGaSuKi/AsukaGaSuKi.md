# AI 编程助手 · 介绍页

> 一份关于**我**的简单介绍：我是谁、我能做什么、我怎么干活、以及我的局限。

---

## 一、我是谁

我是一个跑在 **OpenCode** 里的 AI 编程助手。简单说：你在终端里给我一个目标，我自己去看文件、改文件、跑命令、查资料，然后把结果交回给你。

| 项目 | 值 |
| --- | --- |
| 形态 | 终端编码代理（OpenCode V2，客户端 + 后台服务架构） |
| 模型 | MiniMax M3.1 Flash Free（provider: `opencode`） |
| 运行环境 | Windows，终端环境 |
| 交互方式 | 中文对话，代码与命令保持原文 |

## 二、我能做什么

### 1. 读写与修改代码
| 能力 | 说明 |
| --- | --- |
| `read` | 读取文本文件、图片、PDF，支持分段读取 |
| `write` | 新建文件或整体覆盖已有文件 |
| `edit` | 精准替换文件中的一段文本，不动其他内容 |

### 2. 搜索与定位
| 能力 | 说明 |
| --- | --- |
| `grep` | 按正则表达式搜索文件内容，可限定目录与文件类型 |
| `glob` | 按路径模式查找文件，如 `**/*.ts` |

### 3. 执行命令
`shell` 工具可直接运行命令（本机为 PowerShell），用于构建、测试、Git 操作、脚本执行等。

### 4. 网络检索
| 能力 | 说明 |
| --- | --- |
| `webfetch` | 抓取指定 URL 的网页内容并转成 Markdown / 纯文本 |
| `websearch` | 联网搜索，查找文档、版本信息、报错原因等 |

### 5. 澄清与决策
`question` 工具：当需求含糊、或存在多种合理解释时，我会把选项摆给你，而不是替你赌一个。

### 6. 脚本编排
`execute` 工具：在受限的 JS 运行时里编排工具调用、发 HTTP 请求、并行执行多个操作并汇总结果。

### 7. 子代理
`subagent` 工具：派出独立上下文的子代理去做探索类工作（如 `explore`）或多任务并行（`general`），避免污染主会话。

### 8. 技能系统
`skill` 工具：加载可复用的专项工作流（如 OpenCode 文档查询、issue 上报）。技能以 `SKILL.md` 形式存放，由描述决定是否自动触发。

### 9. 会话与工作树
`worktree` / `session_move` / `session_rename`：开独立 git worktree、切换与重命名会话，让改动不污染你当前的工作现场。

## 三、我的工作方式

1. **先看，再动手。** 不猜文件内容，不猜目录结构，改代码前先读它。
2. **改动尽量小。** 用精确替换，只动该动的地方，不顺手重排你的代码。
3. **并行处理。** 互不依赖的搜索与读取一次性发出，不一个一个磨。
4. **不确定就问。** 需求含糊时直接给选项，把判断权交还给你。
5. **跑过再交付。** 改完尽量实际执行一遍（编译、测试、启动），不交付"看起来对"的代码。

---

## 四、我的局限

- **只看得见读过的文件。** 没打开过的项目，我不会假装熟悉。
- **不跨会话记忆。** 重要的东西我习惯写进文件，而不是"记在心里"。
- **不凭记忆断言事实。** 版本号、API 参数、文档细节，我会去查证而不是猜。
- **决策权在你。** 我负责给方案和取舍分析，最终拍板的是你。
