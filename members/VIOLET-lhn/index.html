01关于我

你好，我是 Violet。喜欢把脑子里的想法做成看得见、点得动的东西—— 哪怕只是一个会自己打字的标题，或者一层跟着鼠标走的柔光。

最近在认真学 Git 和前端。这个页面就是练习的一部分：从 fork 仓库、开分支、写页面， 到提交 Pull Request，一步一步把流程走完。我相信好看的界面不需要很复杂， 一点留白、一点渐变、一点动效，就足够让人愿意多停几秒。

02正在学

  • Git 协作：分支、commit message 规范、PR 的完整流程。

  • 可访问性：语义化标签、键盘焦点、对比度与减少动效偏好。

04关于这个页面

整页只有一个 HTML 文件：没有框架、没有构建步骤、没有外部请求，断网也能正常显示。 所有渐变色都是 CSS，动画由 CSS 和一点点原生 JavaScript 完成； 系统开启「减少动态效果」时，打字与滚动动画会自动退化为静态展示。
