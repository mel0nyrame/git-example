01 · GOAL

目标拆解

把「掌握 Git 与 GitHub 的使用」拆成三个可检验的子目标，学完能独立走通完整的开发协作流程。

会用版本管理

独立使用 Git 管理项目版本：提交、分支、合并、回滚，不再用「最终版 v9」命名文件。

能协作开发

通过 GitHub 与团队协作：规范提交信息、创建 Pull Request、参与 Code Review，完成多人共同开发。

能参与开源

读懂开源项目结构，用 Fork + PR 向真实项目提交第一个贡献，遵循开源协作规范。

02 · ROADMAP

学习路线

按阶段推进，每一阶段都对应可上手的练习：从本地版本管理，一路走到开源协作。

01

Git 基础

建议第 1–2 周

安装配置 Git，理解工作区、暂存区与仓库的关系，学会用提交记录管理项目快照。

git initgit addgit commitgit statusgit log
02

分支与合并

建议第 3–4 周

掌握分支模型：并行开发、合并分支、解决冲突，学会安全地回滚与暂存未完成的工作。

git branchgit checkoutgit mergegit rebasegit reset
03

远程与 GitHub

建议第 5–6 周

把仓库接到 GitHub：关联远程、推送拉取、配置认证，让代码拥有云端副本与公开主页。

git remotegit pushgit pullgit fetchssh-keygen
04

协作与开源

建议第 7–8 周

用 Issues 管理任务、用 PR 提交代码、用 GitHub Flow 组织团队工作流，迈出开源第一步。

ForkPull RequestCode ReviewGitHub Flow
