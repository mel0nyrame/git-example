你好，我是路明非，常驻广州的代码爱好者，也是 GitHub 新手。

我对代码的兴趣，来自那种「敲下几行字，屏幕上就真的出现了一个东西」的魔法感。现在还在打基础，偶尔做点小练习，也会把踩过的坑记下来。享受这种从零开始、边做边学的过程。

比起急着成为高手，我更想保持好奇、保持动手：多读一点，多写一点，也多和厉害的人交流一点。希望有一天，能做出让自己骄傲的作品。
